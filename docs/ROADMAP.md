# ADMWS12 — Feuille de route

## Phase 0 — Page blanche
- définir les objectifs ;
- définir les frontières ;
- définir les principes ;
- définir l'architecture ;
- identifier les références externes sans les intégrer.

## Phase 1 — Fondations
- types fondamentaux ;
- modèle de données ;
- conventions ;
- invariants ;
- système de validation.

## Phase 2 — Plateforme
- modèle matériel ;
- modèle firmware ;
- démarrage ;
- sécurité de plateforme.

## Phase 3 — Sécurité
- modèle de menace ;
- racines de confiance ;
- isolation ;
- vérification.

## Phase 4 — Cryptographie
- hypothèses ;
- construction ;
- paramètres ;
- référence ;
- tests ;
- analyse cryptographique ;
- comparaison reproductible avec les standards existants.

## Phase 5 — Données
- collecte ;
- nettoyage ;
- normalisation ;
- schémas ;
- validation ;
- datasets reproductibles.

## Phase 6 — Logiciels
- bibliothèques ;
- services ;
- outils ;
- interfaces ;
- intégration.

## Phase 7 — Validation
- tests unitaires ;
- intégration ;
- fuzzing ;
- sécurité ;
- performance ;
- compatibilité ;
- reproductibilité.

## Règle

Une phase ne doit pas être déclarée terminée uniquement parce que du code existe. Elle doit disposer de critères de validation vérifiables.
